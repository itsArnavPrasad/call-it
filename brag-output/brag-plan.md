# call-it — brag plan

**What it is:** a Claude Code plugin that calls your phone. Voice notes when a session finishes, needs permission, or asks a question; your voice reply becomes its next move.
**For:** people who start a long Claude Code task and walk away.
**Sets it apart:** voice both ways, approve permissions from anywhere, every session in one Telegram chat, speech stays on your Mac, no server.
**Hook:** the universal pain: you stepped away, and Claude has been stuck on "Do you want to proceed?" ever since. A waiting timer races upward.
**Visual identity:** the README's own look: near-black, Claude orange (#d97757), the Telegram-dark phone from docs/images, SF system type.
**Tone:** default: punchy, playful, clean. Soft transitions, dip through background between busy layouts.
**Share caption:** "Claude Code now calls your phone. Approve, listen and talk back from anywhere."
