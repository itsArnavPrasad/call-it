call-it hooks, in every session

  • ▸ turn.complete → Haiku writes a 3-sentence spoken summary
  • ▸ tool.check “ask” → waits for your Allow / Deny
  • ▸ AskUserQuestion → options as buttons
  • ▸ Notification → “waiting for you” nudges
  • ▸ Shared folder ~/.claude/call-it/
  • one session holds a mkdir lock and polls Telegram,
  • then files each message in the right session's inbox
  • ▸ Routing: swipe-reply → that session;
  • @name … → that session; else the last one that spoke
  • ▸ Your words arrive as a prompt ($.prompt.submit),
  • or as the answer to whatever is waiting
